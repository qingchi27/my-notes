# Java 框架

SSM 是 Java 企业级开发中最经典的技术组合之一，由 **Spring**、**Spring MVC**、**MyBatis** 三大框架构成。在此之上，微服务把单体拆成多服务，需要处理一致性、锁、事务、RPC 与限流等问题。

本模块主要围绕 **Java 后端开发**，系统整理：

- Spring 核心思想（IOC / AOP）与容器机制
- Spring MVC Web 层开发
- MyBatis 持久层框架
- 三大框架整合与实战经验
- 微服务分布式核心面试题

## 学习目标

- 理解 Spring IOC、AOP 的设计思想与实现原理
- 掌握 Spring MVC 请求处理流程与常用注解
- 能独立完成 SSM 三层架构的项目搭建与开发
- 能按「是什么 → 为什么 → 怎么做 → 有什么问题」回答分布式面试题

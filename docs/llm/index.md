# 大模型

大模型面试和工程落地，往往从 **Transformer / 注意力** 讲起，再延伸到训练与推理、Prompt、RAG、Agent。

本模块主要面向 **高级 Java / AI 应用开发**，按以下路径整理：

1. **Transformer 与自注意力** — RNN 对比、QKV、多头、长序列、因果掩码与 KV Cache
2. **Agent 智能体** — 与普通 LLM 的区别、规划 / 记忆 / 工具、ReAct 与工程落地

## 学习目标

- 能用通俗比喻讲清 RNN 与 Transformer 的差异
- 能不看资料复述 Self-Attention 五步与公式
- 能讲清长距离依赖、训练并行、平方级成本，以及因果掩码 / KV Cache
- 能讲清 Agent 四件套，以及 ReAct 的 Observation 反馈闭环

# Java 基础

Java 是一门面向对象的编程语言，广泛应用于企业级后端开发、分布式系统与微服务架构。

本模块主要围绕 **Java 后端开发**，系统整理：

1. **Java 语言基础** — 运行原理、语法与 OOP、包装类与 String、异常泛型、反射与 SPI、IO、序列化与版本
2. **JVM** — 内存区域、类加载、垃圾回收与调优
3. **并发编程** — JMM、锁、CAS/AQS、线程池

## 学习目标

- 掌握 Java 核心语法与面向对象思想
- 理解并发编程基础概念与常见用法
- 能在实际项目中正确、稳定地使用 Java

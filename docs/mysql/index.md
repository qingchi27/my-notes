# MySQL 学习笔记

MySQL 是最常用的开源关系型数据库，Java 后端开发中几乎必用。

本模块主要围绕 **Java 后端开发 / 面试**，按以下路径系统整理 MySQL：

1. **SQL 语法** — DDL / DML / DQL / DCL 与常用写法
2. **存储引擎** — InnoDB / MyISAM 对比与选型
3. **索引** — B+Tree、索引类型、最左前缀与优化
4. **事务** — ACID、隔离级别、MVCC
5. **锁** — 行锁、间隙锁、死锁与排查
6. **日志** — redo / undo / binlog 与两阶段提交
7. **高性能** — 慢查询、执行计划、分库分表思路

## 学习目标

- 能正确编写与优化常见 SQL
- 理解 InnoDB 索引、事务、锁与日志的协作关系
- 能定位慢查询，并给出可行的性能优化方案

# 初识 Redis

## 1. 什么是 Redis？

Redis（Remote Dictionary Server）是一个**基于内存的高性能键值存储数据库**，采用 **Key-Value** 数据结构存储数据。

### 1.1 Redis 主要用于什么？

- 缓存热点数据，提高系统访问速度
- 降低数据库访问压力
- 实现一些高性能的数据结构操作，如计数器、排行榜、分布式锁等

### 1.2 Redis 有哪些特点？

- 数据主要存储在内存中，读写速度非常快
- 支持丰富的数据类型：
  - String
  - Hash
  - List
  - Set
  - ZSet
  - Stream 等
- 支持数据持久化，可以将内存数据保存到磁盘


---

## 2. 使用 Redis 有哪些好处？

### 2.1 访问速度快

Redis 基于内存存储，避免磁盘 IO，读写性能非常高。

典型性能：

- 单节点读取可达到约 **10万 QPS**
- 单节点写入可达到约 **10万 QPS**

（实际性能受硬件、网络、数据结构、业务场景影响）

### 2.2 降低数据库压力

将热点数据存储到 Redis：

减少 MySQL 查询次数，降低数据库压力，提高系统吞吐量。

### 2.3 提升接口响应速度

相比查询数据库：

- Redis：内存访问，微秒级响应
- MySQL：涉及磁盘 IO、SQL 执行、索引查询，耗时更高

使用 Redis 可以明显降低接口响应时间。


---

## 3. 为什么使用 MySQL 存储，Redis 做缓存？

因为两者定位不同。

### 3.1 MySQL 的定位是什么？

MySQL 是**关系型数据库**。

特点：

- 基于磁盘存储
- 支持事务
- 支持复杂查询
- 数据结构固定，需要提前设计表结构

适合存储：

- 用户信息
- 订单数据
- 商品数据
- 业务核心数据

### 3.2 Redis 的定位是什么？

Redis 是**内存型数据库 / 缓存系统**。

特点：

- 基于内存存储
- 读写速度快
- 支持丰富的数据结构
- 适合高频访问的数据

适合存储：

- 热点数据
- 临时数据
- 高频访问数据

### 3.3 为什么结合使用？

常见架构：

```text
用户请求
    |
    ↓
 Redis缓存
    |
缓存不存在
    |
    ↓
  MySQL
```

Redis 负责快速访问，MySQL 负责数据持久化。

优点：

- 提升访问速度
- 降低 MySQL 压力
- 提高系统并发能力

# Redis 学习笔记

Redis 是一个高性能的内存数据库，广泛用于缓存、分布式锁、消息队列、计数器等场景。

本模块主要围绕 **Java 后端开发**，按以下路径系统整理 Redis：

1. **初识 Redis** — 定位、优势、与 MySQL 的分工
2. **Redis 数据对象** — 五大数据类型与底层编码
3. **Redis 执行** — 单线程模型、命令处理与事务/Pipeline
4. **Redis 持久化** — RDB / AOF 与混合持久化
5. **内存淘汰策略** — 过期删除与 maxmemory 策略
6. **Redis 场景** — 缓存、Session、排行榜等实战用法
7. **分布式锁** — 实现方式、可靠性与常见坑
8. **Redis 集群** — 主从、哨兵与 Cluster

## 学习目标

- 理解 Redis 核心数据结构和运行机制
- 掌握缓存设计与高并发问题解决方案
- 能在实际项目中正确、稳定地使用 Redis
